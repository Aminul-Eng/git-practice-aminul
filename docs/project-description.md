# Project Description

## Overview

This project is created for the Module 8 Git & GitHub Practical Assignment.

It demonstrates basic Git version control, branching, merging, and GitHub collaboration workflow.

## Calculator Features

The Python calculator currently supports:

- Addition
- Subtraction
- Multiplication

## Python Files

### `src/main.py`

The main program:

- Displays the student's name
- Displays today's date
- Calls the calculator functions
- Displays calculation results

### `src/utils.py`

Contains reusable calculator functions:

- `add(a, b)`
- `subtract(a, b)`
- `multiply(a, b)`

## Git Workflow

The project demonstrates:

1. Git repository initialization
2. Multiple commits
3. Feature branch creation
4. Feature development
5. Branch merging
6. Branch deletion
7. GitHub remote configuration
8. Pushing local commits to GitHub
